# 法官輔助

法官一個人拿著手機主持：工具依遊戲進度顯示**要唸的台詞**與**要記錄的夜晚行動**，法官輸入結果後，白天會告訴你正確的**死訊或平安夜**，並保存整場遊戲紀錄。網址：`/judge/`。

## 開始一局

有兩種方式：

1. **從角色發牌交過來（建議）**：發完牌後按「交給法官輔助」。板子、規則、每個座位的角色都已帶入，畫面直接進入**進階設定**，夜晚只要記錄行動。
2. **在法官輔助選板子**：按「新遊戲」，選人數與板子。第一晚每個角色睜眼時，點選睜眼玩家的座位，工具就記住誰是什麼角色；狼人睜眼時一次點選所有狼人。狼王、白狼王和狼人一起睜眼時，請他們舉手示意，在同一步點選誰是狼王、誰是白狼王（狼王不與狼隊見面時才會單獨請他睜眼）。白癡、騎士會在第一晚最後另外請他睜眼向法官確認身份。第一晚結束後，沒被點到的座位都是村民。

### 進階設定

選好板子後按「下一步」進入**進階設定**。這裡的選項依板子的角色而不同，只會出現板子裡有的角色相關的設定；板子沒有可調整的項目時顯示「無進階設定」。設定在這一局開始後固定，會顯示在遊戲紀錄中。

| 設定                     | 出現條件 | 預設   | 說明                                                                                           |
| ------------------------ | -------- | ------ | ---------------------------------------------------------------------------------------------- |
| 女巫是否可以自救         | 有女巫   | 都不行 | 都不行／都可以／第一晚可以／第一晚不行                                                         |
| 解藥用完後仍告知女巫刀口 | 有女巫   | 關     | 開啟後，女巫用掉解藥仍會被告知誰被殺（只能看，不能再救）                                       |
| 守衛可以守自己           | 有守衛   | 開     | 關閉後，守衛不能選擇自己                                                                       |
| 狼王與狼隊見面           | 有狼王   | 開     | 關閉後，狼王晚上不和狼人一起睜眼、不參與殺人，狼人也不知道他是誰；其他狼人全部出局後才加入殺人 |
| 狼王自爆後可以開槍       | 有狼王   | 關     | 開啟後，狼王白天自爆後仍可以開槍帶走一人                                                       |

遊戲名稱也在這一步填寫，可以留空，會自動命名為「2026-11-22 第1場」。

## 主持畫面

- 上方顯示**第 N 夜／第 N 天**，板子未驗證時會顯示「未驗證」。
- **台詞**：照著唸即可。
- **輸入結果**：點選座位（再點一次取消）。可以不選人的項目有明確的按鈕：空守、空刀、不魅惑、不詛咒、不使用毒藥、不交換、沒有警長、不開槍、撕毀警徽、平票或無人出局。**防呆**：每個項目都選好之前不能按確認；第一晚狼人必須點滿所有睜眼的狼人（畫面會顯示「已選／應選」），預言家一定要查驗一人。
- **剛剛發生**：上一步造成的結果，例如「5 號出局（被放逐）」「白癡翻牌」。
- 右上角：**復原上一步**（可一直往回）、**座位表**（每個座位的角色、存活、出局原因、警長、情侶；角色記錯可以「修正角色」）。
- 下方「結束遊戲」：手動選擇勝方結束。

### 出局的角色

某個神職已經出局，輪到他時工具仍會顯示台詞，並提示「已出局：照常唸台詞，停頓幾秒假裝等待」。這樣其他玩家無法從法官有沒有叫某個角色判斷他是否出局。

## 夜晚

依[夜晚順序](/rules/night-order)逐一進行。幾個重點：

- **女巫**：工具顯示刀口（「今晚 7 號玩家被殺」）並依進階設定判斷能不能用解藥救自己。**解藥用完後不再告知刀口**（可在進階設定改為仍告知）。同一晚只能用一瓶藥。
- **預言家**：點選查驗對象後立即顯示要比的手勢（好人／狼人）。隱狼查驗為好人。
- **守墓人**：直接顯示前一天被放逐者是好人或狼人。
- **獵人**：顯示今晚的開槍狀態（被毒就不能開槍）。
- **魔術師**：交換的兩人，當晚所有指向他們的行動都會互換，工具自動處理。

## 白天

1. 第 1 天若板子有警長：先**警長競選**（輸入當選者，昨晚死亡的玩家也能當選，因為大家還不知道他死了）。
2. **公布死訊**：工具顯示「昨晚是平安夜」或「昨晚 3 號、7 號死亡」，以及誰可以發表遺言。
3. 依需要處理技能：被狼殺的獵人／狼王**開槍**、出局的警長**移交或撕毀警徽**。
4. 白天行動，三選一：
   - **放逐投票**：輸入被放逐的座位，或平票／無人出局。白癡第一次被放逐會翻牌免死。
   - **自爆**：狼人自爆後直接入夜；白狼王自爆可以帶走一名玩家。
   - **騎士決鬥**：對方是狼人則狼人出局並入夜；否則騎士出局，繼續白天。
5. 每次有人出局都會檢查勝負，分出勝負時遊戲結束。

詳細規則見[白天與勝負](/rules/day)。

## 遊戲紀錄

- **自動保存**：每次輸入都會保存，關掉再開回到同一步，可以從列表繼續主持。
- **列表**：搜尋名稱、板子或備註；依「進行中／好人勝／狼人勝／第三方勝」篩選。每一筆右側的 **⋯（更多選項）** 可以繼續主持或檢視紀錄、用相同設定再開一局、匯出 JSON，或**刪除**（刪除前會再確認一次）。
- **紀錄頁**：結果、板子、座位表、每一夜每一天的**過程時間軸**；可以修改名稱與備註。
- **匯出**：紀錄頁右上角的匯出按鈕（或列表的 ⋯ →「匯出」），有四種格式：
  - **文字**：可讀的摘要（結果、板子設定、座位表、每一夜每一天的過程），可以複製、下載 `.txt` 或分享。
  - **JSON**：完整資料，可以下載或複製，之後能從「資料備份」匯入。
  - **圖片**：同樣內容的 PNG 長圖（Tokyo Night 配色），可以下載或分享；手機上用「分享」→「儲存影像」存進相簿。
  - **連結**：整場紀錄壓縮在約 200 字元的網址裡。對方開啟後會看到整場資訊（結果、板子與設定、進階設定、備註、座位表、每一夜每一天的過程），確認後按「匯入到本機」保存。
- **匯出 JSON**：單場檔案。
- **用相同設定再開一局**：同一個板子與座位角色，從第一晚重新開始。

### 備份與匯入

列表右上角「設定」→「資料備份」：

- **匯出全部（JSON）**：所有遊戲存成一個檔案。
- **從檔案匯入**：可以是單場或多場。和本機重複的紀錄會另存一份，不會覆蓋。

# 開始使用

狼人殺工具集（<https://werewolf.mirumo.net/>）由幾個獨立的工具組成：

| 工具     | 網址      | 用途                                                               |
| -------- | --------- | ------------------------------------------------------------------ |
| 首頁     | `/`       | 工具列表、主題與語言設定、資訊頁（版本、空間用量、更新紀錄、授權） |
| 角色發牌 | `/deal/`  | 一支手機輪流傳，每位玩家查看自己的角色                             |
| 法官輔助 | `/judge/` | 依進度提示台詞與夜晚行動，算出死訊並保存遊戲紀錄                   |
| 使用說明 | `/docs/`  | 就是這個網站                                                       |

::: warning alpha
**角色發牌**與**法官輔助**目前是 **alpha**：功能可以使用，但還在調整，資料格式也可能改變。首頁的工具卡片與這兩個工具的標題旁會顯示 `alpha`。
:::

## 安裝成 App

每個工具都可以單獨安裝，安裝後可以離線使用：

- **iPhone／iPad（Safari）**：打開工具 → 分享按鈕 → 「加入主畫面」。
- **Android（Chrome）**：打開工具 → 右上角選單 → 「安裝應用程式」或「加到主畫面」。
- **電腦（Chrome／Edge）**：網址列右側的安裝圖示。

你可以只安裝首頁，從首頁開啟各個工具；也可以分別安裝角色發牌與法官輔助。

### 從首頁 App 回到首頁

從首頁（或首頁安裝的 App）點進某個工具時，工具的**標題可以點**，標題左邊會有一個箭頭，點了就回到首頁。單獨安裝的工具沒有首頁，所以標題不能點。

## 每次開啟都會檢查更新

開啟 App（或從背景回來超過 5 分鐘）時會先顯示「檢查更新中…」，有新版本就立即更新並重新載入；離線或網路太慢時最多等 6 秒就直接進入。

## 語言與主題

- **語言**：預設為**繁體中文**，可以在任何工具的「設定」切換成 English。所有工具同步，不需要每個都改。
- **主題**：Tokyo Night，有「跟隨系統」、Night、Storm、Light 四種，同樣所有工具同步。

## 「未驗證」標記

選擇板子時，有些板子旁邊會顯示 <span class="ww-unverified">⚠ 未驗證</span>。意思是**這個板子的法官邏輯（夜晚順序、死訊計算、勝負判定）還沒有經過人工驗證**，使用時請自己再確認一次結果。驗證過的內建板子會在之後的版本移除標記；自訂板子一律顯示「未驗證」。詳見[「未驗證」標記](/dev/verification)。

## 資料存在哪裡

所有資料只存在你的手機或電腦的瀏覽器中，不會上傳。清除瀏覽器資料會一併刪除，重要的法官紀錄可以[匯出成 JSON](/guide/judge#備份與匯入) 備份。

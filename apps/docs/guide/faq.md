# 常見問題

### 可以離線使用嗎？

可以。開啟過一次（或安裝成 App）之後，沒有網路也能使用全部功能。

### 換手機時資料會跟著走嗎？

不會，資料只存在這台裝置的瀏覽器。法官輔助的紀錄可以在設定的「資料備份」匯出 JSON，到新手機再匯入；單場紀錄也能用分享連結或 QR code 傳過去。自訂板子可以用分享連結傳過去。

### 法官輔助算出來的死訊和我想的不一樣？

先確認板子設定（例如「同守同救」是否會死）與開局時的進階設定（例如女巫能否自救）是否和你們的規則一致。若板子標示「未驗證」，代表這部分邏輯還沒人工確認過，歡迎回報。輸入錯了可以按「復原上一步」，角色記錯可以在「座位表」修正。

### 狼人怎麼知道隊友是誰？

角色發牌的卡片只顯示自己的角色，不列出隊友。狼人在第一晚由法官叫醒時睜眼互認（狼王也一起）。若你們玩「狼王不與狼隊見面」，在法官輔助的進階設定關閉「狼王與狼隊見面」。

### 為什麼預設是中文？

所有工具預設使用繁體中文，不看瀏覽器的語言。可以在設定切換為 English，所有工具會一起切換。

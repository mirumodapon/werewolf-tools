# 常見問題

### 可以離線使用嗎？

可以。開啟過一次（或安裝成 App）之後，沒有網路也能使用全部功能。

### 換手機時資料會跟著走嗎？

不會，資料只存在這台裝置的瀏覽器。法官輔助的紀錄可以在設定的「資料備份」匯出 JSON，到新手機再匯入；單場紀錄也能用分享連結或 QR code 傳過去。自訂板子可以用分享連結傳過去。

### 法官輔助算出來的死訊和我想的不一樣？

先確認板子設定（例如「同守同救」是否會死、女巫能否自救）是否和你們的規則一致。若板子標示「未驗證」，代表這部分邏輯還沒人工確認過，歡迎回報。輸入錯了可以按「復原上一步」，角色記錯可以在「座位表」修正。

### 為什麼狼人卡片看得到狼王？

狼王是狼人陣營的一員，其他狼人知道他是同伴（「座位號＋角色」模式還會看到他是狼王）。只有隱狼不被同伴看見。

### 為什麼預設是中文？

所有工具預設使用繁體中文，不看瀏覽器的語言。可以在設定切換為 English，所有工具會一起切換。

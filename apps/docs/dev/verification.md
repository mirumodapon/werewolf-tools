# 「未驗證」標記

角色發牌與法官輔助在選擇板子時，會在**未經人工驗證**的板子旁顯示「未驗證」，法官輔助的主持畫面與紀錄也會顯示。

## 意思

法官輔助的夜晚順序、死訊計算與勝負判定是程式依規則推導的。不同角色組合會走到不同的規則分支（例如魔術師交換加上狼美人魅惑、人狼戀的勝負），**沒有人實際照著一個板子完整驗證過之前，結果可能有錯**。標記提醒法官自行確認。

- 內建板子在 `packages/werewolf-rules/src/boards.ts` 以 `verified` 欄位控制，目前全部是 `false`。
- 自訂板子一律未驗證（`verified: false`，無法修改）。
- 遊戲紀錄存的是開局時的板子，但「未驗證」依**目前版本**的內建板子判斷：之後某個板子驗證通過，舊紀錄也會跟著移除標記。

## 如何移除標記

由維護者在發佈新版本時決定：

1. 用該板子實際主持（或對照規則逐步走過）幾局，涵蓋各角色的技能與勝負情況。
2. 有問題就修正規則引擎並補測試。
3. 確認無誤後，在 `boards.ts` 該板子加上 `verified: true`：

   ```ts
   builtin({
     players: 12,
     slug: 'seer-witch-hunter-guard',
     // …
     verified: true,
   }),
   ```

4. 更新 `boards.test.ts` 中「are all unverified」的測試（改成列出已驗證的板子），並在 `CHANGELOG.md` 記下哪些板子已驗證。

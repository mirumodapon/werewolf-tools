# 遊戲流程與名詞

## 陣營

- **狼人陣營**：狼人與特殊狼（狼王、白狼王、狼美人、隱狼）。晚上一起殺人，白天偽裝成好人。
- **好人陣營**：**神職**（預言家、女巫、獵人、守衛……）與**村民**（平民）。
- **第三方**：丘比特、混血兒、野孩子。依情況加入某一方，或與情侶成為獨立陣營。

## 一局的流程

1. **發牌**：每人拿一張角色牌，只有自己知道（[角色發牌](/guide/deal)）。法官不算座位、不拿牌。
2. **夜晚**：法官宣布「天黑請閉眼」，依[夜晚順序](/rules/night-order)請各角色睜眼行動。
3. **白天**：法官公布昨晚的死訊（或平安夜），第一天可以先競選警長；接著依序發言、放逐投票。
4. 重複夜晚與白天，直到一方達成[勝利條件](/rules/day#勝負)。

## 常見名詞

| 名詞       | 意思                                                     |
| ---------- | -------------------------------------------------------- |
| 平安夜     | 夜晚沒有人死亡（守衛守對人、女巫救人、狼人空刀）         |
| 首刀       | 第一晚狼人殺的人                                         |
| 空刀       | 狼人當晚不殺人                                           |
| 空守       | 守衛當晚不守任何人                                       |
| 金水       | 被預言家驗為好人的玩家                                   |
| 查殺       | 被預言家驗為狼人的玩家                                   |
| 銀水       | 被女巫救起的玩家                                         |
| 同守同救   | 守衛守護的人同時被女巫救，依板子設定可能會死（俗稱奶穿） |
| 上警／警下 | 參加／不參加警長競選                                     |
| 警徽流     | 預言家預先說好若出局，警徽要交給誰，藉此傳遞查驗結果     |
| 歸票       | 警長在發言最後建議要放逐誰                               |
| 自爆       | 狼人在白天公開身份出局，直接進入黑夜                     |
| 屠邊       | 狼人殺光所有神職或所有村民即獲勝                         |
| 屠城       | 狼人要殺光所有好人才獲勝                                 |
| 遺言       | 出局玩家最後的發言                                       |

規則各地不同，本工具集把常見差異做成[板子設定](/rules/board-settings)，開局前請和大家確認。

# 夜晚順序與台詞

法官輔助依下列順序呼叫板子裡有的角色。各地習慣不完全相同，這是本工具採用的順序。

| 順序 | 角色       | 何時 | 行動                                                                                                                                     |
| ---- | ---------- | ---- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 0    | 全體       | 每晚 | 「天黑請閉眼」                                                                                                                           |
| 1    | 丘比特     | 首夜 | 連結兩名情侶                                                                                                                             |
| 2    | 情侶       | 首夜 | 法官拍兩人肩膀，睜眼互相確認                                                                                                             |
| 3    | 混血兒     | 首夜 | 選擇榜樣                                                                                                                                 |
| 4    | 野孩子     | 首夜 | 選擇榜樣                                                                                                                                 |
| 5    | 魔術師     | 每晚 | 交換兩人（可不換）                                                                                                                       |
| 6    | 守衛       | 每晚 | 守護一人（可空守，不能連兩晚同一人）                                                                                                     |
| 7    | 狼人       | 每晚 | 首夜互認同伴；決定殺誰（可空刀）。含狼王（進階設定「狼王與狼隊見面」關閉時除外）、白狼王、狼美人；野孩子變狼後加入；隱狼在同伴全滅後加入 |
| 8    | 狼王       | 首夜 | 只有進階設定「狼王與狼隊見面」關閉時：單獨睜眼向法官確認身份。與狼隊見面時，狼王、白狼王在狼人階段舉手示意，由法官一併記下               |
| 9    | 狼美人     | 每晚 | 魅惑一人                                                                                                                                 |
| 10   | 隱狼       | 首夜 | 睜眼，狼人舉手讓隱狼確認同伴                                                                                                             |
| 11   | 女巫       | 每晚 | 告知刀口（解藥用完後不告知）；救或毒，一晚一瓶                                                                                           |
| 12   | 預言家     | 每晚 | 查驗一人，法官比手勢                                                                                                                     |
| 13   | 守墓人     | 每晚 | 得知前一天被放逐者的陣營                                                                                                                 |
| 14   | 烏鴉       | 每晚 | 詛咒一人                                                                                                                                 |
| 15   | 獵人       | 每晚 | 法官比手勢告知今晚能否開槍（被毒則不能）                                                                                                 |
| 16   | 白癡、騎士 | 首夜 | 睜眼向法官確認身份（不知道座位時）                                                                                                       |

**出局的角色照常呼叫**：唸完台詞、停頓幾秒假裝等待，再繼續。這樣其他人無法從流程推測誰已經出局。

## 夜晚結算

天亮時依序判斷：

1. **魔術師**：先把當晚所有行動中被交換的兩人互換。
2. **狼刀**：被殺的人如果被守衛守護**或**被女巫救，就存活；**同時**被守又被救，依板子的「同守同救」設定（預設會死）。
3. **毒藥**：被毒的人一定出局（守衛擋不住）。
4. **連帶死亡**：狼美人出局 → 被魅惑者殉情；情侶一方出局 → 另一方殉情。
5. **野孩子**：榜樣出局後變成狼人。
6. 死者依座位號由小到大公布，不公布死因。

## 台詞範例

以 12 人預女獵守為例：

> 天黑請閉眼。
> 守衛請睜眼，今晚要守護誰？守衛請閉眼。
> 狼人請睜眼，互相確認同伴。今晚要殺誰？狼人請閉眼。
> 女巫請睜眼。今晚 7 號玩家被殺，你要使用解藥嗎？你要使用毒藥嗎？要毒誰？女巫請閉眼。
> 預言家請睜眼，今晚要查驗誰？他的身份是……（比手勢）預言家請閉眼。
> 獵人請睜眼，你今晚的開槍狀態是……（比手勢）獵人請閉眼。
> 天亮了。請想參加警長競選的玩家舉手……
> 昨晚是平安夜。／昨晚 7 號死亡，請 7 號發表遺言。

手勢慣例：大拇指向上＝好人／可以開槍；向下＝狼人／不能開槍。

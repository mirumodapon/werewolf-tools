# 板子設定

每個板子除了角色張數，還有以下設定。內建板子已經填好，自訂板子在編輯頁的「板子設定」調整。角色發牌只顯示這些設定；**法官輔助會依設定計算**。

| 設定           | 選項                             | 預設                    | 說明                                           |
| -------------- | -------------------------------- | ----------------------- | ---------------------------------------------- |
| 勝利條件       | 屠邊／屠城                       | 屠邊（8、9 人板為屠城） | 見[勝負](/rules/day#勝負)                      |
| 女巫自救       | 不能自救／僅首夜可自救／可以自救 | 僅首夜可自救            | 女巫被狼殺時能不能用解藥救自己                 |
| 同守同救       | 會死／不會死                     | 會死                    | 被守衛守護又被女巫救的人是否死亡（奶穿）       |
| 警長競選       | 有／無                           | 有（8、9 人板為無）     | 第 1 天公布死訊前競選警長；警長歸票、算 1.5 票 |
| 夜晚死亡的遺言 | 僅首夜／每晚都有／沒有           | 僅首夜                  | 被放逐的玩家一律有遺言                         |

另外有一欄**規則備註**（文字），可以寫工具不處理的約定，例如平票 PK 方式。

## 固定的規則

以下規則目前不能調整：

- 女巫同一晚只能用一瓶藥；解藥用完後法官不再告知刀口。
- 守衛不能連續兩晚守同一人，可以守自己、可以空守。
- 毒藥無視守衛；被毒、殉情、自爆的獵人與狼王不能開槍。
- 白癡第一次被放逐翻牌免死，之後不能投票。
- 騎士整局只能決鬥一次。
- 魔術師交換影響當晚所有行動。
- 分出勝負時遊戲立即結束。

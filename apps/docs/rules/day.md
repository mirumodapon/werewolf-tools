# 白天與勝負

## 白天流程

1. **警長競選**（第 1 天，板子設定有警長時）：想當警長的人上警發言、可以退水，其餘玩家投票。工具在公布死訊**之前**進行，所以昨晚死亡的人也可能當選，之後再移交警徽。
2. **公布死訊**：平安夜，或依座位號公布死者（不說死因）。
3. **遺言**：依板子設定，預設只有**首夜**死亡的玩家有遺言；被放逐的玩家一定有遺言；自爆、被白狼王帶走、決鬥出局沒有遺言。
4. **技能**：
   - **獵人／狼王**出局時可以開槍帶走一人（被毒、殉情時不能；狼王自爆後預設不能，可在進階設定調整）。被帶走的若也是獵人或狼王，同樣可以開槍。
   - **警長**出局時移交警徽給一名存活玩家，或撕毀警徽（之後沒有警長）。
5. **發言與放逐投票**：警長歸票，投票時算 1.5 票；被烏鴉詛咒的人多一票；翻牌的白癡不能投票。平票時可依你們的規則 PK 或無人出局，在工具中選「平票或無人出局」。
6. 白天也可能發生：
   - **自爆**：狼人公開身份出局，白天立即結束、進入黑夜。白狼王自爆時可帶走一人。
   - **騎士決鬥**：在投票前進行。決鬥狼人成功時直接入夜。
7. 入夜。

## 勝負

每次有人出局都會檢查：

| 結果           | 條件                                   |
| -------------- | -------------------------------------- |
| 好人勝         | 狼人陣營全部出局（且沒有存活的第三方） |
| 狼人勝（屠邊） | 所有**神職**出局，或所有**村民**出局   |
| 狼人勝（屠城） | 所有好人出局                           |
| 第三方勝       | 人狼戀時，場上只剩情侶（與丘比特）     |
| 無人勝利       | 全部出局                               |

- 狼人陣營包含狼王、白狼王、狼美人、隱狼，以及變成狼人的野孩子、榜樣是狼人的混血兒。
- 屠邊時，混血兒（榜樣為好人）、未變身的野孩子、丘比特（非人狼戀）算在村民這一邊。
- 第三方存活時，好人與狼人都還不能獲勝。
- 一方達成條件時遊戲立即結束（之後的開槍等技能不再發動）。法官也可以隨時在工具中手動結束遊戲。
